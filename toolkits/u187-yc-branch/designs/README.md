# designs/ — add your own design

1. Open `http://localhost:5173/?toolkit=u187-yc-branch`, choose **Create project**, and draw your rooms.
2. Use **Project > Export project**. Give the exported file and scenario name to your assistant to extract that scenario's design as `designs/<name>.json`, with `metadata.name` and `metadata.description`.
3. Run `npm run check:toolkit -- -t u187-yc-branch` again. Your design will appear in **Open toolkit design…**.

This folder contains only this README until you add a design.
