# Add your flat design

1. Open the app with `?toolkit=u073-yl-flat`, choose **Create project** and draw your flat.
2. Choose **Project › Export project**. In the exported file, copy your scenario's `design` object into this folder as `<name>.json`. Give it a `metadata.name` and `metadata.description`.
3. Run `npm.cmd run check:toolkit -- -t u073-yl-flat`. Your saved design will appear under **Open toolkit design…**.
