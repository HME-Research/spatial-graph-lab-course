# Add a design

1. Create a project with this toolkit and draw your house in the app.
2. Choose **Project › Export project**. Save the chosen scenario's `design` from the exported project as `designs/<name>.json`. Give it a `metadata.name` and `metadata.description`.
3. Run `npm run check:toolkit -- -t u680-kw-branch` to check the design and run the algorithms on it.
