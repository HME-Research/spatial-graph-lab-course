# Library

Plan a library with Library Hall (bookshelves), Private Study Areas (desks), Toilets, Staff Office and Entrance. Shelf and desk counts start at zero in their respective rooms.

Run `npm run dev`, open http://localhost:5173/?toolkit=u946-sj-library and create a Library project. Draw a Library Hall three cells wide and two deep (54 m²). In Transform, run **Set large halls to 10 bookshelves** and apply the preview. This sets each existing hall over 50 m² of nominal plan area to 10 shelves on any storey. In Analyse > Network, run **Count library bookshelves** to total the bookshelves in all halls.

To start with a layout, choose **Open toolkit design… → Library starter**. The hall starts with six bookshelves and the private study room has four desks. Apply the large-hall transform and run the bookshelf count again to see the total rise to ten.

To add another design, follow the instructions in designs/README.md.
