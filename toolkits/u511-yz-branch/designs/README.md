# Community designs

`community-resilience-courtyard.json` is a generated single-storey community concept requested by the student: six homes, a medical centre, a resource hub, two shelters and a circulation loop around a central shared space. Open **Community Resilience Courtyard** through **Open toolkit design…**. The toolkit README explains the layout and illustrative data. No `defaultDesign` is set.

## Add another design

Draw a design in the app with `?toolkit=u511-yz-branch`, then use **Project > Export project**. Take one scenario's `design` from that file (or copy **Data > JSON**) and save it here as `<name>.json`, with `metadata.name` and `metadata.description`. You can ask your assistant to extract your chosen scenario.

Run `npm run check:toolkit -- -t u511-yz-branch` again. Your design will appear in **Open toolkit design…** under Community Resilience Toolkit.
