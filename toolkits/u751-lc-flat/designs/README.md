# designs/ - add your own design

1. Open the app with ?toolkit=u751-lc-flat, choose **Create project**, and draw your design.
2. Use **Project > Export project**. Ask your assistant to extract your chosen scenario's design into designs/<name>.json, with metadata.name and metadata.description. The design text is also available in **Data > JSON**.
3. Run npm run check:toolkit -- -t u751-lc-flat again. Your design will appear in **Open toolkit design...**.

This folder contains only this README until you add a design. No default design is set.
