# Add your own design

1. Open `http://localhost:5173/?toolkit=u493-ek-roomforfacade`, choose **Create project**, and draw your design.
2. Use **Project > Export project**. Ask your assistant to extract your chosen scenario's `design` as `designs/<name>.json`, with `metadata.name` and `metadata.description`. The Data view's JSON also contains the design.
3. Save that design JSON here and rerun `npm run check:toolkit -- -t u493-ek-roomforfacade`. It will then appear in **Open toolkit design…**.

This folder intentionally contains only this README until you add a design.
