# designs/ — your designs

`two-storey-house.json` is your starting house graph: 11 rooms across two levels, with 10 relationships. Open it using **Open toolkit design…** › **Two-storey three-bedroom house**.

To add another design, draw or edit it in the app with this toolkit, then use **Project › Export project**. Add the chosen scenario's design as `designs/<name>.json` with `metadata.name` and `metadata.description`. Run the toolkit check again after adding it.
