# Add a design

1. Create a project with **Courtyard Shared House** and draw your design.
2. Choose **Project › Export project**. Copy the chosen scenario's `design` object into `designs/<name>.json` and give its metadata a name and description.
3. Run `npm run check:toolkit -- -t u039-ak-courtyard-shared-house`. Use **Open toolkit design…** to reopen it.
