# Add a design

1. Open the app with `?toolkit=u821-dc-test01`, choose **Create project** and draw your house.
2. Use **Data › JSON** to copy the design, or take your scenario's `design` from **Project › Export project**.
3. Add a `metadata.name` and `metadata.description`, then save it here as `<name>.json`. It will appear under **Open toolkit design…**.
4. Run `npm run check:toolkit -- -t u821-dc-test01` to check the design and run the algorithms on it.
