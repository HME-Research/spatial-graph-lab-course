Set up your computer

Once, at the start: install three programs, join the course repository on GitHub, copy it to your computer and run the app there. About 30 minutes. Only needed to make a toolkit; to use the app or upload an analysis, a browser is enough.

1. Install the programs

  1. A GitHub accountMake one at github.com/signup (free) and send your username to your tutor. Students can also apply for free extras at GitHub Education.
  2. GitDownload from git-scm.com/downloads and install with the default options. On a Mac, typing git in Terminal also offers to install it.
  3. Node.jsDownload the LTS version (22 or newer) from nodejs.org and install with the default options. It brings npm, which installs and runs the app.
  4. VS CodeDownload from code.visualstudio.com. You will open the repository in it, and run commands in its terminal: Terminal › New Terminal.
  5. Check themIn a new VS Code terminal, run: 
    git --version
node --version

    two version numbers; Node must start with 22 or higher. A message such as “not recognized” means the program is not installed yet, or VS Code was open while you installed it: close and reopen VS Code.

2. Join the course repository

  1. Accept the invitationYour tutor adds you to HME-Research/spatial-graph-lab-course. Accept it from the e-mail GitHub sends, or at its invitations page. Without it you can copy the repository but not push your work.
  2. Tell Git who you are (once per computer; use the e-mail of your GitHub account): 
    git config --global user.name "Your Name"
git config --global user.email "you@example.com"

3. Copy the repository to your computer

This is called cloning. Choose one way.

In the VS Code terminal

  1. Go to the folder that should hold itfor example your Documents folder: 
    cd ~/Documents
  2. Clone it 
    git clone https://github.com/HME-Research/spatial-graph-lab-course.git

    a new folder spatial-graph-lab-course. The first time, a browser window may ask you to sign in to GitHub: allow it.

  3. Open it in VS CodeFile › Open Folder… › Documents/spatial-graph-lab-course. Answer “Yes, I trust the authors” if asked.

Or with GitHub Desktop (no typing)

Install GitHub Desktop, sign in, then File › Clone repository… › HME-Research/spatial-graph-lab-course › Clone, and Open in Visual Studio Code. GitHub Desktop can also make branches, commit and push for you (see Git).

4. Run the app on your computer

  1. Install what the app needs (once, and again whenever the course says so). In the VS Code terminal, inside the repository folder: 
    npm install

    “added … packages” after a minute or two. Warnings are fine; an ERR! is not (see Help).

  2. Start it 
    npm run dev

    a line such as Local: http://localhost:5173/. Ctrl-click it, or open it in your browser: the app's Welcome screen.

  3. Stop it when you are done: click in the terminal and press Ctrl+C. While it runs, the app reloads by itself when a file changes.

Windows: “running scripts is disabled on this system”? Run this once in the terminal, then try again: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned (answer Y).

You are ready. Next: plan your toolkit.
