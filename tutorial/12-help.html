When something goes wrong

Find the message or symptom below and open it. With an AI assistant, the quickest fix is usually to paste it the whole message and ask it to fix exactly that, inside your toolkit folder.

01Setting up

My GitHub verification email hasn't arrived
  1. Check your spam or junk folder.
  2. Check that the email address you entered is correct.
  3. Use GitHub's option to resend the verification email.
I downloaded Visual Studio, not Visual Studio Code
  1. Go back to the official VS Code download page.
  2. Download Visual Studio Code, the lighter code editor, not Visual Studio.
  3. Run the installer and open Visual Studio Code.
git, node or npm “is not recognized” / “command not found”
  1. Close all VS Code windows and restart VS Code, so that its terminal sees the new program.
  2. Open Terminal › New Terminal and try git --version, node --version or npm --version again.
  3. If it still fails, install it again (Set up › 03 for Git, 04 for Node.js, with the official LTS installer).
macOS asks me to install Command Line Tools
  1. Choose Install when prompted.
  2. Let the installation finish.
  3. Close and reopen Terminal and run git --version again.
Windows PowerShell says running scripts is disabled
  1. In VS Code, open Terminal › New Terminal.
  2. Use the arrow next to the + in the terminal panel and select Command Prompt (to make it the default: Select Default Profile › Command Prompt, Set up › 07).
  3. Run your npm command there.

You do not need to change Windows security settings.

My Node.js version number is different from the example
  1. That is normal: a version beginning with v for Node.js and a number for npm, rather than an error. The app needs Node.js 22.12 or newer.
I can't find Extensions or Agent mode in VS Code
  1. Open View › Extensions, or the Extensions icon in the left sidebar, and search for the official extension of your agent.
  2. No Agent mode: restart or update VS Code, confirm you are signed in and the extension is enabled.
The agent asks for payment or shows a usage limit
  1. Do not buy anything just to complete the checklist.
  2. Check whether Copilot Free or GitHub Education is available to you.
  3. Ask the tutor if you are unsure which option to choose.
npm install shows ERR!
  1. Check you are in the repository folder (it contains package.json).
  2. Check that node --version is 22.12 or higher.
  3. Run it again.
“Port 5173 is in use, trying another one…”
  1. The app is probably already running in another terminal: use that one, or stop it there with Ctrl+C and start it again.
  2. Otherwise open the address this one printed (for example http://localhost:5174/), and use it wherever these pages say localhost:5173.
“The system cannot find the path specified” when going to source\repos
  1. The folder does not exist yet: run the mkdir line first (Set up › 09).

02The terminal and the folder

Commands fail with “not a git repository” or “Could not read package.json”
  1. The terminal is in the wrong folder.
  2. File › Open Folder… › spatial-graph-lab-course, then open a new terminal (how to check).
A command keeps running and the prompt doesn't come back
  1. Press Ctrl+C in the terminal (also on a Mac).
  2. To keep the app running and type other commands, open a second terminal with the +.
Git opened a strange text editor
  1. That is a merge message after git pull or git merge.
  2. Vim (a ~ on every line): type :wq and press Enter. A VS Code tab: save and close it.

03Git and GitHub

Push refused: “protected branch”, “rule violations” or “cannot update this protected ref”
  1. You are pushing main. Your work belongs on your branch: Git basics › I committed on main.
“Permission denied” or “Repository not found” when pushing
  1. Accept the course invitation (Set up › 06).
  2. Sign in to GitHub when Git asks (Signing in, Windows and macOS).
The Mac terminal asks for a Username and Password
  1. Your GitHub password is not accepted there: press Ctrl+C.
  2. Push from VS Code's terminal and allow VS Code to sign in, or use GitHub Desktop (Signing in).
Push refused: “Cannot create ref due to creations being restricted”
  1. The branch name does not start with toolkit/: make the branch again with exactly toolkit/<toolkit-id> (Create your branch).
“Updates were rejected because the remote contains work that you do not have”
  1. On your first push of this branch: the id is already taken by someone else's branch. Never pull it: choose another id (Create your branch).
  2. You pushed this branch before (for example from another computer): run git pull --no-rebase, then git push.
“fatal: Need to specify how to reconcile divergent branches”
  1. On your branch: use git pull --no-rebase.
  2. On main: you committed on main (Git basics › I committed on main).
git status lists files outside my folder
  1. Don't commit them.
  2. Put them back: Git basics › I changed a file outside my folder.
“A branch named … already exists”
  1. Use git switch toolkit/<toolkit-id> without -c.
My toolkit id is already used by someone else's branch
  1. Never pull or push to their branch. Add a letter to your initials or change your toolkit name (Check the name is free), and push the new branch at once to reserve it.
  2. Never rename a toolkit after you pushed it; ask your tutor if that happened.
A red ✗ on GitHub
  1. Click Details next to the failing check and read the red lines.
  2. Then see Hand in › Red ✗.

04Getting the course's updates

“CONFLICT” after git merge main
  1. Run git merge --abort.
  2. Ask your tutor (Get the course's updates). Never edit files outside your folder to make it go away.
“Your local changes to the following files would be overwritten”
  1. Commit your toolkit's changes first, or undo changes outside your folder.
  2. Run the update steps again.
“fatal: invalid reference: toolkit/…”
  1. The branch name is wrong: run git branch and use exactly the name it lists.

05Your toolkit

toolkit folder "…" must be lowercase letters…
  1. Rename the folder: lowercase letters, digits and -, starting with a letter, as <initials>-<toolkit-name>.
No toolkit "…" was found
  1. The folder is missing or has another name: it must be toolkits/<toolkit-id>/ with toolkit.ts directly inside it.
  2. If the message names a folder to rename, rename it to exactly your id. Check you typed the id after -t correctly.
toolkit.ts is one folder too deep
  1. The folder is toolkits/<toolkit-id>/<toolkit-id>/toolkit.ts instead of toolkits/<toolkit-id>/toolkit.ts (a common unzip mistake; see Chat assistant › Put the folder in place).
  2. Move the contents of the inner folder up one level and delete the empty inner folder.
My toolkit is not in the Toolkit list or in Open example…
  1. Run npm run check:toolkit -- -t <toolkit-id>: it says what is wrong.
  2. Check the address too: ?toolkit=<toolkit-id>.
A Function or algorithm is disabled
  1. Select it, or read Project › Advanced, for the reason: usually an invalid field or a duplicate id.
… imports … refused by a check
  1. Toolkit code may import only @student-api and files in your own folder.
  2. No npm packages, nothing from lab/ or another toolkit.
An algorithm fails on the default design
  1. Run it in the app on that design to see its message.
  2. Usually a missing value (null) or an empty list it did not expect.
The browser tab freezes
  1. An endless loop in an algorithm: every while must end.
  2. Close the tab, fix the loop, reopen.
Designs show “unknown Function” warnings
  1. A Function id was renamed or removed.
  2. Add it back (ids are forever), or fix the designs.
The AI wants to change lab/, package.json or install a package
  1. Say no. The fix always belongs in your toolkit folder.
  2. If the API cannot do something, ask the AI for the closest thing it can do.
The chat gave code blocks, not a zip
  1. Ask “Please give me the folder as a zip”.
  2. If it cannot, make each file yourself in VS Code with exactly the path written above its block.

06An uploaded analysis or transform

My chat refuses the zip file
  1. Try another chat (claude.ai, chatgpt.com or gemini.google.com).
  2. Or ask your tutor.
The file is refused
  1. Check the file really ends in .ts, not .ts.txt (Your own analysis › Save).
  2. Paste the app's whole message to the AI and ask it to fix exactly that.
“Stopped after … s — does it loop forever?”
  1. It took too long.
  2. Ask the AI to make it simpler or to make every loop end.
My analysis is not in the section I expected
  1. The section follows its input: none → Network, one node → Node, one edge → Edge, anything else → Queries.
“This file is an analysis … upload it in Analyse”
  1. It only reads and shows an answer: upload it in Analyse (Your own analysis). In Analyse, a transform gets the opposite message.
The transform preview shows an error
  1. Paste the app's whole message to the AI and ask it to fix exactly that.
  2. Use ↻ (Replace) in Yours (Your own transform).
“customOf needs a Function from a toolkit's functions/ folder…”
  1. Ask the AI to read the fields with ctx.nodeCustom(nodeId) instead.
Apply is greyed out: “The design has changed since this preview was computed”
  1. You edited the design after Run: press Run again.
My project is gone
  1. Projects live in one browser on one computer: check you are in the same one, not in a private window.
  2. Open your last exported .project.json (Use the app › Keep your work).

07Still stuck?

Ask your tutor or in the workshop Slack channel, with: what you did, your operating system, the step, the whole message (copied, not a photo), your branch name, and the output of git status. Please don't post passwords, API keys or authentication codes.
