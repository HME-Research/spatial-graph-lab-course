Write your own transform

Optional. A transform proposes changes to your design: you see a preview first, nothing changes until you press Apply, and one Undo reverses all of it. An AI chat writes it as one file; you upload it in your browser.

Orange text like <toolkit-id> = replace it with your own. Grey buttons like Copy = something to click.

Transform kit (recommended)

The transform can read each node's Function, size, position and level, each edge's relationship and calculated values such as area. Works in any project.

Download the Transform kit (.zip)

03

Save the file it gives you

One .ts file, with the name the AI suggests.

Download the file the chat offers, for example connect-touching-rooms.ts. Only code shown? Ask “Please give me this as a file”, or save it yourself as on page 3 (the name must end in .ts, not .ts.txt).

04

Upload it, preview it, Apply it

Nothing changes until you press Apply.
  1. UploadTransform › Upload your own (.ts) › choose the file.

    it is listed under Yours, with its settings.

  2. Run itChoose it, set its settings (an empty field uses the default) and press Run.

    a preview: what it would add, move, resize or set. Your design has not changed yet.

  3. Apply or DiscardApply changes the design in one step; Discard drops the preview. Changed your mind after Apply? One Undo reverses it all.
  4. Refused, or an error in the preview?Copy the app's whole message into the chat and ask: “Fix exactly this.” Then use ↻ (Replace) beside it in Yours with the new file.

An analysis (it only reads) is refused here: upload it in Analyse (page 3). Uploaded transforms are saved with your project, and the same file works in a toolkit's algorithms/ folder.

Problems: Apply is greyed out · “customOf needs a Function…” · all upload problems.
