Make a toolkit with a chat assistant

A chat assistant (Claude, ChatGPT or Gemini in the browser) cannot see the repository. You give it the toolkit kit, it gives you your toolkit folder, and you put that folder in place, check it, commit and push.

Before you start: set up your computer and plan your toolkit.

The commands below use it once you type it.

1. Get your toolkit from the chat

  1. Download the toolkit kitToolkit kit (.zip), also in the app: Guide › Toolkits & JSON › Make your own toolkit › Chat assistant › Toolkit kit (.zip). It holds the AI's instructions (PROMPT.md), the guide, the Student API reference, the starter toolkit and the House toolkit as an example.
  2. Open a new chat and attach the zip.If your chat refuses zip files, unzip it and attach the files inside.
  3. Send your promptThe one Plan a toolkit built for you, or this one with the blanks filled in: 
    I've attached the Spatial Graph Lab toolkit kit. Read PROMPT.md and every file in it, then write my toolkit following it exactly. Give me the folder <toolkit-id>/ as a zip; if you cannot make files, give every file in its own code block, headed by its path.

Toolkit id: ___
My idea: ___
Functions (and their attributes): ___
Algorithms: ___
Example design: ___
  4. Read its summaryIt lists your Functions, attributes, algorithms and designs, and anything it chose for you. Ask for changes now, in plain words, before you download.
  5. Download the zipIf it gave code blocks instead, ask “Please give me the folder as a zip”; if it cannot, make each file yourself in VS Code with exactly the path written above its block.

2. Make your branch

In VS Code, open the repository (File › Open Folder… › spatial-graph-lab-course) and a terminal (Terminal › New Terminal):

git switch main
git pull
git switch -c toolkit/<toolkit-id>

Switched to a new branch 'toolkit/<toolkit-id>'. Already made it earlier? git switch toolkit/<toolkit-id> (no -c). With GitHub Desktop: Current branch › New branch › toolkit/<toolkit-id>.

3. Put the folder in place

Unzip the chat's zip (Windows: right-click › Extract All…; Mac: double-click) and move the folder <toolkit-id> into the repository's toolkits folder. toolkit.ts must sit directly inside it:

✓ Right✗ Wrong (a common unzip mistake)
spatial-graph-lab-course/ toolkits/ house/ <toolkit-id>/ toolkit.ts functions/ algorithms/ designs/
spatial-graph-lab-course/ toolkits/ <toolkit-id>/ <toolkit-id>/ toolkit.ts …
Move the inner folder up one level.

4. Check it and try it

  1. Install (first time only, or after the course says so): 
    npm install
  2. Run the checks 
    npm run check:toolkit -- -t <toolkit-id>
npm run typecheck

    both end without a red FAIL or error. check:toolkit loads your toolkit as the app does and runs every algorithm on your default design; typecheck checks the TypeScript.

  3. If a check failsCopy the whole message into the chat and ask: “Fix exactly this and give me only the files you changed.” Replace those files in your folder and run the checks again. More in Help.
  4. Try it in the app 
    npm run dev
    Open http://localhost:5173/?toolkit=<toolkit-id> › Open example… › Toolkit: your toolkit's name. Run your analyses in Analyse and transforms in Transform. Stop with Ctrl+C.

5. Commit and push

git add toolkits/<toolkit-id>
git status

git status must list only files under toolkits/<toolkit-id>/ in green. If it lists anything else, don't commit: see Help to undo that change first.

git commit -m "feat(<toolkit-id>): first version of my toolkit"
git push -u origin toolkit/<toolkit-id>

With GitHub Desktop: tick only your toolkit's files, write a summary, Commit to toolkit/<toolkit-id>, then Publish branch. Then check the green tick on GitHub.

All the commands at once

The same steps as one list, as the app shows them (lines starting with # are things you do by hand):

git switch main
git pull
git switch -c toolkit/<toolkit-id>
# unzip: the folder must end up at toolkits/<toolkit-id>/ (toolkit.ts directly inside it)
npm install
npm run check:toolkit -- -t <toolkit-id>
npm run typecheck
npm run dev
# try it at http://localhost:5173/?toolkit=<toolkit-id>, then stop the server (Ctrl+C)
git add toolkits/<toolkit-id>
git status
git commit -m "feat(<toolkit-id>): first version of my toolkit"
git push -u origin toolkit/<toolkit-id>

Later changes

Send the chat the files you changed (or your whole folder as a zip) so it works on your current version, not its first answer. Then replace the files, check, commit and push again: Update.
