Write your own transform

Ask an AI chat for a transform in plain words, upload the one file it writes, and run it on your design. A transform proposes changes: you see them first as a preview, nothing changes until you press Apply, and one Undo reverses all of it. Only a browser and an AI chat that accepts attachments are needed.

1. Decide three things

PartQuestionExample
IdeaWhat should it do to your design?Connect every two rooms that touch but have no edge yet.
ParametersWhat do you want to set in Transform before it runs: a number of cells, Access or Open, a Function…? Or nothing.Access or Open.
ChangesWhat may it change: add nodes, add edges, move or resize rooms, set a node's or an edge's value?Add edges.

2. Choose a kit

A kit is a zip with the instructions the AI follows, the exact functions and changes it may use, and examples. In the app: Transform › the ⓘ beside Upload your own (.ts).

KitThe transform can useWorks inGet it
Transform kiteach node's Function, size, position and level, each edge's relationship, calculated values such as area, and the Functions found in your designany projecttransform kit (.zip), or ⓘ › Any project
Transform kit for this projectalso your project's Functions and custom fields (such as a target area or a priority), listed in its PROJECT.mdprojects that have themonly in the app: open your project, ⓘ › This project

Prefer to write it yourself? ⓘ › Template gives a commented file to change.

3. Ask the AI

  1. Open a new chat and attach the kit zip.If your chat refuses zip files, unzip it (Windows: right-click › Extract All…; Mac: double-click) and attach the files inside instead.
  2. Send the starting text for your kit, with the three blanks filled in.
    Transform kit
    I've attached the Spatial Graph Lab transform kit. Read PROMPT.md and every file in it, then write ONE transform that works in any project (node basics only, no custom fields).

My idea: ___
Parameters I want to set: ___
What it should change: ___
    Transform kit for this project
    I've attached the Spatial Graph Lab transform kit for my project. Read PROMPT.md, PROJECT.md and every file in it, then write ONE transform that follows them exactly. It may use my project's Functions and custom fields as PROJECT.md lists them.

My idea: ___
Parameters I want to set: ___
What it should change: ___
  3. Save its answer as a .ts filewith the name it suggests, for example connect-touching-rooms.ts: download it if the chat offers a file, or paste the code into a new file in VS Code (or Notepad / TextEdit as plain text) and save it with that name.

    Windows hides file extensions: a file saved as connect.ts.txt looks like connect.ts but is refused. In File Explorer, View › Show › File name extensions shows the real name.

4. Upload it, run it, Apply it

  1. UploadIn the app, open Transform › Upload your own (.ts) › choose the file.

    it is listed under Yours, with its parameters.

  2. Run itChoose it, set its parameters (an empty field uses the default) and press Run.

    a preview: the new nodes and edges with the ids they will get, the moved or resized rooms and the changed values. Your design has not changed yet.

  3. Apply or DiscardApply changes the design in one step; Discard drops the preview. Changed the design after Run? The preview is out of date: run it again.
  4. UndoChanged your mind after Apply? One Undo reverses the whole change.
  5. If the app refuses it, or the preview shows an error, copy the app's whole message into the chat and ask: “Fix exactly this.” Save the new answer and use ↻ (Replace) beside it in Yours.

    An analysis (it only reads and shows an answer) is refused here: upload it in Analyse instead (Your analysis).

Uploaded transforms are saved with your project: Export project (see In the browser) keeps them in the file you hand in. The same file also works in a toolkit's algorithms/ folder.
