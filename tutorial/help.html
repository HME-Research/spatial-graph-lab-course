When something goes wrong

Find the message or symptom below. With an AI assistant, the quickest fix is usually to paste it the whole message and ask it to fix exactly that, inside your toolkit folder.

Setting up

Message or symptomWhat to do
git, node or npm “is not recognized” / “command not found”Install it (Set up), then close and reopen VS Code so its terminal sees it.
“running scripts is disabled on this system” (Windows)Run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once, answer Y.
npm install shows ERR!Check you are in the repository folder (it contains package.json) and that node --version is 22 or higher. Then run it again.
“Port 5173 is in use”The app is already running in another terminal: use that one, or stop it with Ctrl+C. Vite may also pick the next port: open the address it prints.
Commands fail with “not a git repository” or “Could not read package.json”The terminal is in the wrong folder. File › Open Folder… › spatial-graph-lab-course, then open a new terminal.

Your toolkit

Message or symptomWhat to do
toolkit folder "…" must be lowercase letters…Rename the folder: lowercase letters, digits and -, starting with a letter.
The app says your toolkit doesn't existThe folder must be toolkits/<toolkit-id>/toolkit.ts, not toolkits/<toolkit-id>/<toolkit-id>/toolkit.ts (a common unzip mistake; see Chat assistant › 3). Check the address too: ?toolkit=<toolkit-id>.
A Function or algorithm is disabledSelect it, or read the Project panel, for the reason: usually an invalid field or a duplicate id.
… imports … refused by a checkToolkit code may import only @student-api and files in your own folder. No npm packages, nothing from lab/ or another toolkit.
An algorithm fails on the default designRun it in the app on that design to see its message. Usually a missing value (null) or an empty list it did not expect.
The browser tab freezesAn endless loop in an algorithm: every while must end. Close the tab, fix the loop, reopen.
Designs show “unknown Function” warningsA Function id was renamed or removed. Add it back (ids are forever), or fix the designs.
The AI wants to change lab/, package.json or install a packageSay no. The fix always belongs in your toolkit folder; if the API cannot do something, ask the AI for the closest thing it can do.

Git and GitHub

Message or symptomWhat to do
Push refused: “protected branch”, “rule violations” or “cannot update this protected ref”You are pushing main. Your work belongs on your branch: Git › I committed on main.
“Permission denied” or “Repository not found” when pushingAccept the course invitation (Set up › 2) and sign in to GitHub when Git asks.
“Updates were rejected because the remote contains work that you do not have”Someone (or you, on another computer) pushed to your branch. Run git pull, then git push.
git status lists files outside your folderDon't commit them: Git › I changed a file outside my folder.
“A branch named … already exists”Use git switch toolkit/<toolkit-id> without -c.
A red ✗ on GitHubHand in › Red ✗.
“CONFLICT” after git merge maingit merge --abort and ask your tutor (Update).

An uploaded analysis

Message or symptomWhat to do
The file is refusedPaste the app's whole message to the AI and ask it to fix exactly that. Check the file really ends in .ts (Your analysis).
“Stopped after … s — does it loop forever?”The analysis took too long; ask the AI to make it simpler or to make every loop end.
It is not in the section you expectedThe section follows its input: none → Network, one node → Node, one edge → Edge, anything else → Queries.

An uploaded transform

Message or symptomWhat to do
“This file is an analysis … upload it in Analyse”It only reads and shows an answer: upload it in Analyse (Your analysis). In Analyse, a transform gets the opposite message.
The file is refused, or the preview shows an errorPaste the app's whole message to the AI and ask it to fix exactly that, then use ↻ (Replace) in Yours (Your transform).
“customOf needs a Function from a toolkit's functions/ folder…”Ask the AI to read the fields with ctx.nodeCustom(nodeId) instead.
Apply is greyed out: “The design has changed since this preview was computed”You edited the design after Run: press Run again.
“Stopped after … s — does it loop forever?”The transform took too long; ask the AI to make it simpler or to make every loop end.

Still stuck?

Ask your tutor, with: what you did, the whole message (copied, not a photo), your branch name, and the output of git status.
