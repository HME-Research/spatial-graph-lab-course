Make your branch and plan your toolkit

Exercise 2 starts here: name your toolkit, make your branch and send it to GitHub, then write your plan. This page turns it into the prompt for your AI.

Before this page you need: the course folder open in VS Code, with npm ci done (see Clone the repository).

Orange text like <your-toolkit-name> = replace it with your own. Grey buttons like Copy = something to click.

01

Your toolkit name

The name of your folder and your branch.

u + the last 3 digits of your student number + your initials + a short toolkit name, lowercase, joined with -. Student number …123, initials HK, toolkit House: u123-hk-house.

U
All of it, or only the last 3 digits: only the last 3 are kept.

Toolkit name
<your-toolkit-name>
Folder
toolkits/<your-toolkit-name>/
Branch
toolkit/<your-toolkit-name>

Remembered only in this browser. The commands below fill in with it.

Choose it once: don't rename it later.

Public. Your toolkit name, branch, README and commit name can be read by anyone. Only the last 3 digits of your student number go in it: put no full student number, passwords or keys anywhere.

What will my toolkit folder contain? (optional)
toolkits/<your-toolkit-name>/ toolkit.ts its name, its default design, the attributes every node / edge has README.md what it is for and how to try it (your tutor reads this) functions/ one Function per file: Bedroom, Kitchen… algorithms/ one analysis or transform per file designs/ example designs (.json), shown in Open example… assets/ optional: Rhino .3dm façade files lib/ optional: helper code shared by several algorithms

Your AI writes these files. A complete example is the House example, toolkits/house/ (read it, never change it).

02

Make your branch and send it to GitHub

Before any AI work, in VS Code's terminal.

In VS Code's terminal, in the course folder. Is npm run dev running there? Open a second terminal with +. One command at a time:

  1. Check where you are 
    git status

    On branch main as the first line: go on.

    It says “On branch” something else

    Go to the course version first, so that your branch starts from it:

    git switch main

    “not a git repository”? The terminal is in the wrong folder: Help.

  2. Get the newest course version 
    git pull

    “Already up to date.” or a list of updated files.

  3. Make your branch and go to it-c means “create it first”. 
    git switch -c toolkit/<your-toolkit-name>

    Switched to a new branch 'toolkit/<your-toolkit-name>'.

  4. Make its first commitAn empty one, so that the branch has something to send. 
    git commit --allow-empty -m "chore(<your-toolkit-name>): start my toolkit"

    [toolkit/<your-toolkit-name> …] chore(…): start my toolkit.

    Git says “Please tell me who you are”? Do this once, then run the commit again.

  5. Send it to GitHubThis puts your branch on GitHub. 
    git push -u origin toolkit/<your-toolkit-name>

    * [new branch] toolkit/<your-toolkit-name> -> toolkit/<your-toolkit-name>

    -u remembers GitHub (origin) as the place this branch goes: from now on a plain git push is enough. The first push may open a browser window: sign in and Authorize.

Troubleshooting
“rejected” or “Everything up-to-date” instead of * [new branch]

Not your fault: someone already has a branch with this name. Never pull it. Change your toolkit name a little (another word for the toolkit name) in step 01, then:

git switch main

and run steps 3–5 again with the new name.

“A branch named … already exists”

You made it before: go to it with git switch toolkit/<your-toolkit-name> (no -c), then step 5.

“Permission denied” or 403

Accept the course invitation first (Install the tools › 02), then run step 5 again.

Anything else

Help › Git and GitHub.

the push printed * [new branch], and your branch is listed on the course's branches page.

03

Who will write it: an agent or a chat?

Both end the same way: your folder, checked, pushed.

Coding agent

Codex, Claude Code, GitHub Copilot in Agent mode

  • Works inside VS Code, on your files.
  • Writes your folder and runs the checks.
  • Page 10.

Chat assistant

An AI chat in the browser that accepts a zip file

  • Reads the kit you attach, gives your folder back as a zip.
  • You put it in place and run the checks.
  • Page 11: also when your agent is out of quota.
