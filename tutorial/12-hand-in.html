Submit your work

Your toolkit folder is your hand-in: push your branch to GitHub, or hand in a zip of the folder. Either way, run the checks first.

Orange text like <your-toolkit-name> = replace it with your own. Grey buttons like Copy = something to click.

Your tutor will tell you:

  • where to hand in: to be announced
  • the deadline: to be announced
  • whether the branch or the zip counts: to be announced

Public. The course repository is public: your branch, your README and your commit name can be read by anyone. Put no full student number, passwords or keys in them.

01

Two ways to hand in

The same folder, toolkits/<your-toolkit-name>/.
  • Your pushed branch on GitHub (steps 02–05): your tutor sees it, and GitHub checks it for you.
  • A zip of your folder (step 06), if your tutor asks for one or pushing does not work for you.
02

Push your branch

Your work, committed and on GitHub.

 
npm run check:toolkit -- -t <your-toolkit-name>

PASSED: toolkit "…" is ready. as the last line.

git status

On branch toolkit/<your-toolkit-name> and nothing to commit, working tree clean. Files listed? Commit them first (how).

git push

… -> toolkit/<your-toolkit-name>, or “Everything up-to-date” if it was pushed already.

Never pushed this branch? Something went wrong?
  • Never sent your branch to GitHub: page 09 › Make your branch and send it to GitHub.
  • “Permission denied” / 403 · “GH013 … rule violations” · “GH007 … email privacy” · “src refspec … does not match any”
03

Check it on GitHub

Your folder is there, and a green ✓ is beside your latest commit.
  1. Open your branchThe course's branches › type your initials › click toolkit/<your-toolkit-name>.

    your latest commit message at the top, and your folder inside toolkits/.

  2. Wait for the checkBeside your latest commit a yellow ● turns into a green ✓ or a red ✗ after a few minutes. Click it to see the checks.

The empty first commit has a ✓ too. An empty branch has nothing to check, so it is always green. Your hand-in is complete only when your folder is visible on GitHub and the ✓ is beside your latest commit, the one that contains it.

your folder is on GitHub and your latest commit has a green ✓.

04

Red ✗? Read it and fix it

Click the ✗ › Details, and read the red lines.
The red message saysDo this
This branch changes files outside toolkits/…Put those files back (Help), commit, push.
No toolkit "…" was foundYour folder is not on the branch or has another name: Help.
toolkit.ts is one folder too deepMove the inner folder's contents up one level (Help), commit, push.
a check:toolkit or typecheck errorRun the same check on your laptop, paste the message to your AI, fix it inside your folder, commit, push.
05

Update your README

It is the first thing your tutor reads.

Ask your agent or chat, for example:

Update toolkits/<your-toolkit-name>/README.md for my tutor: my GitHub username, what the toolkit is for, its Functions and attributes, its algorithms (what each shows or changes, and how to run it), its example designs, how to try it (npm run dev, then http://localhost:5173/?toolkit=<your-toolkit-name>), and the design decisions I made. Plain English, short.

Read it, correct it in your own words, then commit and push it like any change.

What a good README contains
  • Your GitHub username and your toolkit name.
  • The idea, in one or two sentences.
  • The Functions (and what each records), the algorithms and the example designs.
  • How to try it, and which analysis or transform to run on which design.
  • Decisions you made and why. No full student number, passwords or keys: it is public.
06

Or: hand in a zip of your folder

When your tutor asks for a zip.
  1. Check firstRun the check (step 02) and make sure it prints PASSED.
  2. Compress your folderThe folder toolkits/<your-toolkit-name> itself, not toolkits and not the whole course folder. In VS Code's explorer, right-click your folder › Reveal in File ExplorerReveal in Finder, then:

    Windows

    Windows 11: right-click the folder › Compress to ZIP file. Older Windows: right-click › Send to › Compressed (zipped) folder.

    macOS

    Right-click the folder › Compress "<your-toolkit-name>".

  3. Name it <your-toolkit-name>.zipInside it there must be the folder <your-toolkit-name>/ with toolkit.ts directly inside: double-click the zip to check.
07

No laptop that can run the app?

Only if your tutor agrees.

Tell your tutor early. If your tutor agrees, hand in your browser work instead: in the app, Project › Export project, and send the .project.json file as your tutor asks (Use the app).
