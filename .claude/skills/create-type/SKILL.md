# Create a node type
1. Read the current extension contract and sample types. If type loading is not implemented yet, stop and explain.
2. Define `id`, friendly label, colour, façade parameters and missing-value defaults. Ask user for essential programme intent only.
3. Create one new student type in `student/types/` without changing core.
4. Confirm external/internal behaviour follows edge context; node function alone never creates a doorway to an adjacent occupied cell.
5. Validate and show how to test by assigning the type to one exposed and one internal node.
